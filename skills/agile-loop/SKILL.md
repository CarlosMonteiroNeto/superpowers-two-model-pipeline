# Agile Loop (overlay)

## When to Use This Skill
- Team setup (PO/SM/Dev team), ceremony facilitation, backlog ordering and slicing.
- Story writing (who/what/why + acceptance), estimation, DoR vs DoD enforcement.

## Route elsewhere
- Requirements ambiguity analysis -> requirements.
- Quality-in-agile demo/TDD/CI mechanics -> quality-gate + verification-test.

## Checklist (grounded: Gestao Agil U1-U4 + Qualidade U4)
1. Roles: PO owns value/order, Dev team owns delivery estimate, SM owns process impediments.
2. Timeboxes: planning 8h/4wk, daily 15min 3-questions, review demo-working-software, retro 3-questions blameless.
3. Backlog: INVEST per story; order by ROI/risk; tasks <=8h; only done counts.
4. Track: planning poker + Fibonacci; burndown updated at daily.
5. Output: refined story + DoR/DoD + ceremony notes for the brief.
