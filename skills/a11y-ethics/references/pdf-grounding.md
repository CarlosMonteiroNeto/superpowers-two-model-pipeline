# PDF Grounding — A11y Ethics (Usabilidade U2/U4)

Sources: usability evaluation (U2), advanced interaction and ethics (U4). English synthesis, no verbatim excerpts.

## Usability Evaluation Essentials
- Plan evaluations around measurable objectives: define user profiles, representative tasks, and acceptance thresholds before recruiting participants or running sessions.
- Compare moderated testing (facilitator probes in real time, rich qualitative insight) against unmoderated testing (larger remote samples, faster turnaround, thinner context).
- Use benchmark testing for longitudinal comparison of releases against fixed task sets, and eye-tracking to reveal attention distribution behind navigation and legibility issues.
- Measure efficiency (mean time on task, action counts), efficacy (completion rate, error rate, assists needed), and satisfaction (standardized questionnaires plus open-ended debriefs).
- Run Nielsen 10-heuristic inspection by classifying each violation under navigation, legibility, or feedback, then prioritizing fixes by severity and frequency.
- Apply WCAG and POUR checks (alt-text, keyboard operability, plain language, robustness) at responsive breakpoints, treating automated validators as a complement to testing with persons with disabilities, never a replacement.

## Advanced Interaction and Ethics Essentials
- Design natural interaction through clear affordance and mapping: controls must signal possible actions and their effects must match user expectations across modalities.
- Support multimodal input and output (touch, voice, gesture, visual feedback) while keeping each channel consistent and providing fallbacks when one channel fails.
- Apply gamification mechanics (points, levels, streaks, social proof) deliberately, and flag manipulation risks such as dark patterns, coerced continuity, and grind loops.
- Personalize with techniques like segmentation, recommendation, and adaptive interfaces, validating changes with controlled A/B comparisons on task and satisfaction metrics.
- Frame ethics reviews around transparency, privacy, equity, and autonomy: users should understand what is personalized, why, and how to change it.
- Control algorithmic bias, consent, and storage risks by auditing training data and outputs, securing explicit consent for profiling, and minimizing retained personal data.
- Publish clear policies, keep user control over personalization settings, and require auditable algorithms whose decisions can be inspected and challenged.
